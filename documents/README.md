# Documents Folder

This folder contains resume and CV files for the portfolio website.

## File Naming Convention

Files should follow this naming pattern:
- Resume: `resume_MMDDYYYY.pdf` (e.g., `resume_11232025.pdf`)
- CV: `cv_MMDDYYYY.pdf` (e.g., `cv_11232025.pdf`)

## Current Files

The website is configured to display:
- **Resume**: `documents/resume.pdf` (symlink or latest version)
- **CV**: `documents/cv.pdf` (symlink or latest version)

## Adding Updated Documents

When you have new versions:
1. Upload the dated file (e.g., `resume_11232025.pdf`)
2. Update the main `resume.pdf` to point to the latest version (or rename/copy the latest)
3. Same process for CV files

## Archive

You can keep older versions in this folder with their dates for version history.
