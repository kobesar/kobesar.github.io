Projects & Work

A collection of data analysis, visualization, and web development projects.

Featured Projects

  • Interactive Boundary Map - Major Qualifying Project featuring an interactive Google Maps visualization with KML boundary overlays and address search functionality. Built with JavaScript and Google Maps API.
  • SVD Analysis - Applied SVD analysis to uncover the polarization of American politics by examining the 90th and 116th congress roll calls. Built with R.
  • NFL Betting 2020 - An interactive web dashboard to visualize NFL betting data and trends using R Shiny.
  • NFL Picks - A fun dashboard visualizing how well my friend and I are predicting NFL games, built with R Shiny.
  • Music Vault - Search through my favorite music artists. Backend built with Node.js, frontend with JavaScript, HTML, and CSS.
  • Survey of American Homelessness - Interactive article exploring the homeless problem in the United States with Vega-Lite visualizations.

Mini-Projects

  • Wordle Score Tracker - Track daily Wordle scores with friends! Features include leaderboard rankings, daily results, tiebreaker logic, and score history. Built with vanilla JavaScript and localStorage.
  • Debt Dashboard - Interactive dashboard utilizing JavaScript to fetch data from APIs and visualize it with Plotly.
  • Crypto Donations - Dashboard tracking cryptocurrency (ETH and BTC) donations made to the Kyiv Independent.
  • Emissions Dashboard - Interactive web dashboard to visualize greenhouse gas emission data and trends, built with R Shiny.
